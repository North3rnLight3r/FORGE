- Added policy-scoped canonical filesystem resolution in `packages/agent-tools/src/index.ts`: Workspace, Repository, Project Tree, Home, and Full user-accessible filesystem. Existing targets/symlink destinations are resolved before scope checks. Agent shell cwd now goes through the same ToolRouter scope check.

- Added persisted execution, network, process, background, task-continuation, argument-repair, and semantic-index preferences to IPC, SettingsService, and Settings UI. Defaults are Controlled + Workspace scope; Controlled is read-only, Allow All authorizes mutations in configured scopes, and Disabled hides/rejects tools.
- Added process timeout caps: Standard is capped at 120 seconds for foreground shell and 10 minutes for background work; Full Local Compute may use the configured longer limits. Task-call continuation now obeys its setting. Tool execution remains serial; the unused concurrency setting was removed.
- Added dynamic ToolRouter capability metadata and `tool.catalog`/`tool.execute` IPC. ToolPanel now displays registered capabilities, schemas, unavailability reasons, generic Run/Test, request cancellation, and Stop All. The generic runner has a task selector and natural-language redirect field for `task.redirect`.
- Added durable task redirect/consumption events, `task.redirect`, state-driven task-step advancement, task-boundary pause/cancel checks, tracked background process cancellation, and Stop All IPC.
- Made semantic context default-on, gated indexing on Auto Index, surfaced index failures as runtime events, and added one bounded rebuild attempt when Auto Repair is enabled.
- Updated the user manual, configuration guide, README, AGENTS.md, architecture/current-status/task/security/semantic docs, and Unreleased changelog. The attempted `docs/TOOLING_GUIDE.md` rewrite did not apply; that file remains stale and should be updated.
